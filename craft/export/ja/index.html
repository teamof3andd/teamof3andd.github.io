あなたの建築を、あなたのワールドへ

ステップはわずかで、各ステップでやることは1つ。完成ワールドなら、開いた時点で建築がもう建っています。今あるワールドに入れるなら、コマンドを1つ入力するだけ。MOD は不要です。

書き出しでできること

Craft Block は画面上の建築を、ゲームが理解できるファイルに変えます。そのファイルを Minecraft で開き、コマンドを1つ入力すると、同じ建築がブロック単位の実寸でワールドに現れます。

?

ボタンの場所

ホーム画面 → 建築を長押し → Minecraft に書き出す。どの建築でも大丈夫です：自分のものでも、サンプルの1つでも。

?

自分はどのエディション？

App Store、Google Play、Microsoft Store から Minecraft を入れた、または Xbox、PlayStation、Switch で遊んでいるなら Bedrock。PC や Mac で Minecraft Launcher から起動しているなら Java。わからないときは、タイトル画面を見てください。Bedrock は隅に v1.21.x のようなバージョンが出ます。Java は Minecraft 1.21.x と Launcher が表示されます。

?

手に入るもの

Bedrock： 完成ワールドかパックのどちらか。完成ワールドは末尾が .mcworld のファイル1つで、新しいワールドとして開きます。パックは末尾が .mcpack のファイル1つで、建築の名前がついたパックがゲームに入ります。Java： 末尾が _datapack.zip の .zip が1つで、ワールドのフォルダに入れます。どれもごく小さく、あなたの建築だけが入っています。

書き出す前にアプリがサイズを表示します：ブロック数、幅、奥行き、高さ。大きな建築は同じファイルの中で複数のパーツに分割されますが、コマンド1つで全部まとめて置かれます。

?

引き継がれるもの、引き継がれないもの

引き継がれる： 階段、ハーフブロック、ドア、松明、ガラス、水、植物を含むすべてのブロックが、あなたの設定した向きのまま。

置き換えられる： Craft Block にしかないブロックが少しあります。アプリがそれぞれと、代わりにゲームで使われるもの（たとえば蓮はピンクのチューリップになります）を一覧にします。黙って消えるものはありません。

アプリに残る： 動物などの生き物（装飾であり、ゲームにはそのブロックがありません）と、読み込んだテクスチャパック（ゲームは自分のテクスチャを使います）。

?

置かれる場所

コマンドを入力したときに立っている場所です。建築は足元から始まり、東と南へ広がるので、まず東を向いてください。詳しい説明と、正確な場所を事前に確認する方法は下の 正確にはどこに現れる？ にあります。

?

何回書き出せる？

無料なのは合計3つの建築までです。ゲームに入れる建築1つにつき無料の書き出しを1回使うので、建築を3つ入れた完成ワールドなら3回すべてを使います。その後は Craft Block Premium の機能になります。ファイル自体に期限はありません。一度手に入れれば、好きなだけ多くのワールドに建築を置けます。

Bedrock でいちばん簡単な方法：完成ワールド

Craft Block が、建築がすでに建っている新しい平らなクリエイティブワールドを作ります。コマンド入力も設定の切り替えも不要で、自分のワールドはそのままです。今あるワールドに建築を入れたい場合は、下の 自分のワールドへ を使ってください。

1

「完成ワールド」を選ぶ

ホーム画面で建築を長押し → Minecraft に書き出す → Bedrock の最初の選択肢 完成ワールド。

2

建築を選ぶ

アプリが どの建築をワールドに入れますか？ と聞いてきます。書き出し中の建築にはすでにチェックが入っています。自分の建築 と 内蔵サンプル から合計 10 件まで追加し、ワールドを作成 を押します。

建築は平らな平原に、列になって並びます。プレミアムのサンプルは Craft Block Premium で一覧に表示されます。 Premiumなしでは建物1つにつき無料の書き出しを1回使うため、残っている回数分だけ追加できます。

3

ワールドをゲームに入れる

.mcworld を保存 を押します。この先は端末によって違います：

Android のスマホ・タブレット： Minecraft が自動で開き、ワールドを取り込みます。そのためにゲームが再起動しますが、正常です。

iPhone・iPad： 共有シートが開きます。Minecraft を選びます。一覧にない場合は "ファイル"に保存 を選び、ファイルアプリを開いてそのファイルをタップします。

4

ワールドを開く

Minecraft で 遊ぶ を押します。ワールド タブにいます。

新しいワールドをタップします。名前は建築と同じで、2 つ追加した場合は末尾に +2 が付きます。エリアを読み込む数秒間、ホットバーの上に ワールドを建築中… と表示されます。

見えるはずのもの：目の前に並んだ建築（数が多いときは小さな高台からスタートします）。クリエイティブなので、飛び回ったり中に入ったりできます。

このワールドでは実績が無効です。 チートがオンになっていて、チートありのワールドでは Minecraft は実績をくれません。それが引き換えで、だからこそ自分のサバイバルワールドには一切手を触れません。下の 自分のワールドへ は逆に自分のワールドでチートをオンにする必要があり、そのワールドの実績は二度と戻りません。

Bedrock：スマホ、タブレット、コンソール、Windows

自分のワールドへ： 今あるワールドに建築を入れます。手順は少し多めです：そのワールドでチートをオンにして、コマンドを 1 つ入力します。

各ステップは1画面ずつ。その下の行に、うまくいったときに見えるはずのものを書いています。画像は Android タブレットと iPhone のもので、Windows でも同じ見た目です。

1

Craft Block から書き出す

ホーム画面で建築を長押し → Minecraft に書き出す → 自分のワールドへ（Bedrock の下） → .mcpack を保存。

次にファイルをゲームに渡します。ここだけ端末によって手順が違います：

Android のスマホ・タブレット： Minecraft が自動で開き、パックを読み込みます。

iPhone・iPad： 共有シートが開きます。Minecraft を選びます。一覧にない場合は "ファイル"に保存 を選び、ファイルアプリを開いてそのファイルをタップします。

Windows 10/11（Microsoft Store 版 Bedrock）： ファイルを PC に送り（メール、OneDrive、ケーブル）、ダブルクリックします。Minecraft が起動して読み込みます。

Xbox、PlayStation、Switch： コンソールはファイルを開けません。スマホか PC でパックを読み込み、そこでワールドに建築を置き、そのワールドを Realm でコンソールに持っていきます（Realms でプレイ → ワールドをアップロード、コンソールから参加）。または、そのワールドをスマホで遊ぶだけでも大丈夫です。

見えるはずのもの：Minecraft の上部に インポートに成功しました と表示されます。

何も起きない、またはファイルが別の場所で開いた？ ファイルを自分宛てに送り（Telegram、Drive、メール）、端末で開いて長押し → アプリで開く → Minecraft。
2

ワールド一覧へ

Minecraft で 遊ぶ を押します。ワールド タブにいます。

新しいワールド：新規作成 → 新しいワールドを作成。既存のワールド：名前の横の 鉛筆 をタップします。名前そのものではありません。

見えるはずのもの：左に項目一覧（一般、ゲーム、リソースパック、ビヘイビアーパック…）が並ぶワールド設定。

3

チートをオンにする

左の一覧 → チート → チート をオン（古いバージョンでは ゲーム の中に チートの実行 としてあります）。このワールドで実績が無効になると警告されますが、問題ありません。はいを選びます。ついでに 一般 → ゲームモード → クリエイティブ にすると建築が楽になります。

見えるはずのもの：チートのスイッチが緑。（「実績は無効」の表示だけでは不十分です。クリエイティブのワールドはチートがオフでもそう表示されます。）

4

このワールドでパックを有効にする

左の一覧 → ビヘイビアーパック → マイパック を開く → 建築の名前のパックをタップ → 有効にする。

ゲームが ワールドを更新しますか？ と聞いてきたら それでもパックを追加 を選びます。ゲームが作っていないものがワールドに入る、という注意にすぎません。

見えるはずのもの：パックが上の 有効 に移動しています。

「有効にする」ボタンがない？ プレイ中のワールドの中にいます。その画面はパックを表示するだけです。ワールドを出て（ポーズ → 保存して終了）、ステップ2のように鉛筆から戻ってください。
5

ワールドに入って場所を決める

作成（新しいワールド）または 遊ぶ（既存）を押します。平らで開けた場所まで歩きます。日の出のときに太陽が 正面 に来るように向きます。それが東です。建築は正面と右側の地面を埋めます。

見えるはずのもの：前方に、アプリが示したサイズ以上の平らな場所。

6

コマンドを入力する

画面上部の 吹き出し をタップしてチャットを開きます。ファイルを保存したとき、アプリがコマンドをクリップボードに入れています：チャット欄を長押し → ペースト。手で打つ場合は、スペースで区切った2語です。function という単語、そして建築の名前。My House という建築なら：

/function craft_my_house

送信を押します。建築がすぐに現れます。

見えるはずのもの：アプリとまったく同じあなたの建築。

「Incorrect permission level for command: function」 チートはオンですが、あなたのプレイヤーがまだオペレーターではありません。ポーズ → ソーシャル（右上）→ 自分の名前をタップ → オペレーター。コマンドをもう一度入力します。
「Unknown command: craft_my_house」 function の単語が抜けています。タッチキーボードでは抜けやすいです。2語です：/function craft_my_house。
「Cheats aren't enabled in this world」 ステップ3ができていません：ポーズ → 設定 → 左の一覧の チート → オン。クリエイティブにしただけではチートはオンになりません。
入力した文字がチャットのメッセージになった 先頭のスラッシュが抜けています。コマンドは / で始まります。iPhone のキーボードでは 123 の中にあります。
「Unknown function」 このワールドでステップ4ができていないか、別のワールドにいます。建築名のスペースはアンダースコアになります：My House → craft_my_house。

Java：PC と Mac

Java は、ワールドのフォルダに入れた小さな .zip ファイルから建築を読み込みます。インストールするものはありません。

1

Craft Block から書き出す

ホーム画面で建築を長押し → Minecraft に書き出す → Java → .zip を保存。ファイルを好きな方法でパソコンに送ります：AirDrop、メール、Telegram、ケーブル。解凍しないでください。

見えるはずのもの：パソコン上の my_house_datapack.zip というファイル。

2

ワールドのフォルダを開く

Mac： Finder で ⌘⇧G を押し、~/Library/Application Support/minecraft/saves を貼り付けて Enter。
Windows： WinR を押し、%appdata%\.minecraft\saves と入力して Enter。
Linux： ~/.minecraft/saves を開きます。

ワールド名のフォルダを開き、その中の datapacks フォルダを開きます。

見えるはずのもの：datapacks というフォルダ（空でも大丈夫、それが普通です）。

3

.zip を入れる

ファイルを datapacks に移動します。zip のままで。

見えるはずのもの：datapacks の中にある .zip。

4

パックを有効にする

ゲームでワールドを開きます。T でチャットを開き、次の2行を順番に入力します。1行目には自分のファイル名を使います：

/datapack enable "file/my_house_datapack.zip" /reload

見えるはずのもの：1行目の後に「Enabled data pack …」、2行目の後に短い停止。

パックが「互換性がない」と出る？ そのまま有効にしてください、読み込まれます。Craft Block 2.6.0 以降の書き出しではこの表示は出ません。
コマンドが動かない？ このワールドはチートがオフです。ポーズ → LAN に公開 → チートの許可：オン → LAN ワールドを開始。クリエイティブのワールドは最初からチートがオンです。
5

場所を決める

平らで開けた場所まで歩きます。F3（Mac：fnF3）を押し、Facing の行が east になるまで向きを変えます。建築は正面と右側の地面を埋めます。

6

コマンドを入力する

T を押してアプリのコマンドを入力します（スマホでは横のコピーボタンでクリップボードに入ります）。Java では コロン が入ります。My House という建築なら：

/function craft:my_house

見えるはずのもの：アプリとまったく同じあなたの建築。

「Unknown function」 ステップ4を飛ばしたか、名前が違います。Java はコロンを使い、スペースはアンダースコアになります：My House → craft:my_house。

正確にはどこに現れる？

足元から、東と南へ広がります。

東（太陽が昇る方向）を向くと、建築は正面と右側の地面を埋めます。幅、奥行き、高さはアプリが教えてくれます。建築はそのまま置かれます：丘の上なら一部が丘の中に埋まり、湖の上なら水が入り込みます。まず平らな地面、それからコマンドです。

プレビューと正確な配置がしたい（ストラクチャーブロック）

ゲーム自身のストラクチャーブロックは、置く前に建築の輪郭を描き、位置の微調整や回転ができます。/give @s structure_block で入手して設置し、開いてモードを ロード にし、名前欄に建築名（両エディションとも craft:my_house）を入力し、境界ボックスをオンにして、輪郭がぴったり収まるまでオフセットを調整し、ロード します。1つのブロックで扱えるのは Java で一辺48ブロック、Bedrock で64ブロックまで。それより大きい建築は複数パーツで届き、アプリが各パーツのオフセットを示します。

何かおかしいときは

ドア、松明、花が消えている

これらは下に固い地面が必要です。建築がくぼみ、穴、水の上に置かれると、読み込んだ瞬間にゲームが落としてしまいます。平らな地面に置くか、先に地面を埋めてください。

水があちこちに流れている

建築に池やプールがあり、地面より上に置かれたので、水がとどまる場所がありませんでした。もっと低く、地面の上に置けば、水は水槽の中にとどまります。

角の階段がまっすぐになった

階段の角の形は、手で置くときと同じように、ゲームが隣のブロックから判断します。隣に階段がない角の階段はまっすぐになり、完成した屋根の中では角になります。

動物がいない

Craft Block の動物は装飾で、ブロックではありません。ゲームにはそのブロックがないので、プランナーの中に残ります。書き出す前にアプリが何匹あるかを教えてくれます。

Xbox、PlayStation、Switch で遊んでいる

コンソールはファイルを開けないので、パックを直接読み込めません。スマホ、タブレット、PC で読み込み（上のステップ1）、ワールドに建築を置いてから、そのワールドを Realm にアップロードし、コンソールから Realm に参加します。Realm がない場合、建築は読み込んだ端末にとどまります。

クリエイティブのワールドでないとだめ？

いいえ。サバイバルを含めどのゲームモードでも大丈夫です。コマンドに必要なのはそのワールドでチートがオンになっていることだけで、チートで失うのはそのワールドの実績だけです。クリエイティブは建築を眺めるのに楽なだけです：飛べますし、何も噛みつきません。

書き出しは無料？

無料なのは合計3つの建築までで、完成ワールドは中の建築1つにつき無料の書き出しを1回使います。その後、書き出しは Craft Block Premium の機能になります。このページのことはすべてゲーム自身が行い、費用はかかりません。
