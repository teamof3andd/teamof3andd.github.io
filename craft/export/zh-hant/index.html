你的建築，放進你自己的世界

只需幾步，每步只做一件事。用現成世界，打開時建築就已經立在那裡；或者輸入一條指令，把建築放進你既有的世界。不需要模組。

匯出是做什麼的

Craft Block 會把螢幕上的建築變成遊戲看得懂的檔案。你在 Minecraft 裡打開這個檔案，輸入一條指令，同樣的建築就會以真實尺寸、一塊一塊地出現在你的世界裡。

?

按鈕在哪裡

主畫面 → 長按一個建築 → 匯出到 Minecraft。任何建築都行：你自己的，或者範例裡的。

?

我玩的是哪個版本？

如果你是從 App Store、Google Play、Microsoft Store 安裝的 Minecraft，或者在 Xbox、PlayStation、Switch 上玩，就是 Bedrock。如果你在 PC 或 Mac 上透過 Minecraft Launcher 啟動，就是 Java。不確定？在遊戲標題畫面上，Bedrock 會在角落顯示類似 v1.21.x 的版本號；Java 顯示 Minecraft 1.21.x 和啟動器。

?

你會得到什麼

Bedrock： 現成世界或套件，二選一。現成世界是一個以 .mcworld 結尾的檔案，打開就是一個新世界；套件是一個以 .mcpack 結尾的檔案，打開後一個以你建築命名的套件會進入遊戲。Java： 一個以 _datapack.zip 結尾的 .zip，放進你的世界資料夾。它們都很小，只包含你的建築，別無其他。

匯出前 App 會顯示尺寸：多少方塊，多寬、多深、多高。大型建築會在同一個檔案裡切成幾個部分；指令仍然一次把它們全部放好。

?

哪些會帶過去，哪些不會

會帶過去： 每一個方塊，包括樓梯、半磚、門、火把、玻璃、水、植物，以及你設定的朝向。

會被取代： 有幾種方塊只存在於 Craft Block。App 會列出每一種以及遊戲裡用什麼代替（例如蓮花會變成粉紅色鬱金香）。不會有東西悄悄遺失。

留在 App 裡： 動物和其他生物（它們是裝飾，遊戲裡沒有對應的方塊），以及你匯入的任何材質包——遊戲使用自己的材質。

?

它落在哪裡

你輸入指令時所站的位置。建築從你腳下開始，向東、向南延伸，所以先面朝東。更多細節和預覽確切位置的方法在下面的 它到底出現在哪裡？。

?

可以匯出幾次？

總共可以免費匯出三個建築。每個進入遊戲的建築都會用掉一次免費匯出，所以放了三個建築的現成世界會用完全部三次。之後匯出屬於 Craft Block Premium。檔案本身永不過期：一旦有了它，你可以把建築放進任意多個世界。

Bedrock 最簡單的方法：現成世界

Craft Block 會建立一個全新的平坦創造模式世界，你的建築已經立在裡面。不用輸入指令，也不用開啟任何設定，你自己的世界完全不受影響。想把建築放進既有的世界？請看下面的放進自己的世界。

1

選擇「現成世界」

在主畫面長按你的建築 → 匯出到 Minecraft → Bedrock 下的第一個選項 現成世界。

2

選擇建築

App 會問 把哪些建築放進世界？ 正在匯出的建築已經勾選。再從 你的建築 和 內建範例 裡加入，總共最多 10 個，然後點 建立世界。

它們會在平坦的平原上一排排並肩而立。開通 Craft Block Premium 後，進階範例才會出現在列表中。 沒有 Premium 時，每個建築會用掉一次免費匯出，所以清單裡能加入的數量就是你剩下的次數。

3

把世界匯入遊戲

點 儲存 .mcworld。接下來依裝置而定：

Android 手機或平板： Minecraft 會自動打開並匯入世界。為此遊戲會重新啟動一次——這是正常的。

iPhone 或 iPad： 會跳出分享面板。選擇 Minecraft。如果列表裡沒有，選擇 儲存到「檔案」，然後打開「檔案」App 並點該檔案。

4

開啟世界

在 Minecraft 裡點 遊玩。你現在在 世界 分頁。

點新世界。它和你的建築同名，如果另外加了兩個，名稱結尾會帶 +2。在區域載入的幾秒鐘裡，快捷欄上方會顯示 正在建造你的世界…。

你應該看到：你的建築就在眼前（建築很多時，你會站在一個小小的高台上）。這是創造模式：可以繞著飛，也可以走進去。

這個世界的成就是關閉的。 那裡開啟了作弊，而 Minecraft 在開了作弊的世界裡不給成就。這就是代價，也正因如此，你自己的生存世界從來不會被動到。下面的 放進自己的世界 則需要在你自己的世界裡開啟作弊，那裡的成就會永久關閉。

Bedrock：手機、平板、主機、Windows

放進自己的世界： 把建築放進你既有的世界。步驟多一些：在那個世界開啟作弊，然後輸入一條指令。

每一步就是一個畫面。每步下面那行字說明成功後你應該看到什麼。圖片來自 Android 平板和 iPhone；Windows 上看起來一樣。

1

從 Craft Block 匯出

在主畫面長按你的建築 → 匯出到 Minecraft → 放進自己的世界（在 Bedrock 下） → 儲存 .mcpack。

然後把檔案送進遊戲——這是唯一一個因裝置而異的步驟：

Android 手機或平板： Minecraft 會自動打開並匯入套件。

iPhone 或 iPad： 會跳出分享面板。選擇 Minecraft。如果列表裡沒有，選擇 儲存到「檔案」，然後打開「檔案」App 並點該檔案。

Windows 10/11（Microsoft Store 版 Bedrock）： 把檔案傳到電腦上（郵件、OneDrive、傳輸線），點兩下它。Minecraft 會啟動並匯入。

Xbox、PlayStation、Switch： 主機無法打開檔案。先在手機或 PC 上匯入套件，在那裡把建築放進一個世界，再透過 Realm 把那個世界帶到主機上（在 Realms 上遊玩 → 上傳世界；然後主機加入）。或者乾脆在手機上玩那個世界。

你應該看到：Minecraft 頂部顯示 匯入成功。

沒有任何反應，或者檔案在別的地方打開了？ 把檔案傳給自己（Telegram、Drive、郵件），在裝置上打開，長按 → 用其他 App 開啟 → Minecraft。
2

進入你的世界列表

在 Minecraft 裡點 遊玩。你現在在 世界 分頁。

新世界：新建 → 建立新世界。既有世界：點名稱旁邊的 鉛筆——不是名稱本身。

你應該看到：世界設定，左側有一列區段（一般、遊戲、資源套件、行為套件……）。

3

開啟作弊

左側列表 → 作弊 → 打開 作弊（舊版本裡它在 遊戲 下，叫 啟用作弊）。遊戲會警告這個世界的成就將被關閉——沒關係，確認即可。順便 一般 → 遊戲模式 → 創造，建造會更輕鬆。

你應該看到：作弊開關是綠色的。（只有「成就已停用」還不夠——創造模式世界在作弊關閉時也會這樣顯示。）

4

為這個世界啟用套件

左側列表 → 行為套件 → 打開 我的套件 → 點帶有你建築名稱的套件 → 啟用。

如果遊戲問 更新世界？，選擇 仍然加入套件——它只是提醒世界裡會出現不是它自己產生的東西。

你應該看到：套件已經移到上方的 已啟用 裡。

沒有「啟用」按鈕？ 你正在一個執行中的世界裡——那個畫面只是顯示套件。離開世界（暫停 → 儲存並離開），然後像第 2 步那樣透過鉛筆回來。
5

進入世界，選好位置

點 建立（新世界）或 遊玩（既有世界）。走到一塊平坦開闊的地面。轉身，讓日出時太陽在你正前方——那就是東方。建築會填滿你前方和右側的地面。

你應該看到：前方有一塊平地，至少和 App 顯示的尺寸一樣大。

6

輸入指令

點螢幕頂部的 對話泡泡 打開聊天。儲存檔案時 App 已經把指令放進了剪貼簿：長按聊天框 → 貼上。或者手動輸入——是用空格隔開的兩個字：function 這個字，然後是你建築的名稱。對於名為 My House 的建築：

/function craft_my_house

點傳送。建築立刻出現。

你應該看到：你的建築，和 App 裡一模一樣。

「Incorrect permission level for command: function」 作弊已開啟，但你的玩家還不是管理員。暫停 → 社群（右上角）→ 點自己的名字 → 管理員。再輸入一次指令。
「Unknown command: craft_my_house」 少了 function 這個字——觸控鍵盤上很容易漏掉。是兩個字：/function craft_my_house。
「Cheats aren't enabled in this world」 第 3 步沒做：暫停 → 設定 → 左側列表裡的 作弊 → 打開。只開創造模式並不會開啟作弊。
你輸入的內容變成了聊天訊息 開頭的斜線不見了。指令以 / 開頭——iPhone 鍵盤上它在 123 裡。
「Unknown function」 這個世界沒做第 4 步，或者你在另一個世界裡。建築名稱裡的空格會變成底線：My House → craft_my_house。

Java：PC 和 Mac

Java 從一個放進你世界資料夾的小 .zip 檔案讀取建築。不用安裝任何東西。

1

從 Craft Block 匯出

在主畫面長按你的建築 → 匯出到 Minecraft → Java → 儲存 .zip。用任何方式把檔案傳到電腦上：AirDrop、郵件、Telegram、傳輸線。不要解壓縮。

你應該看到：電腦上有一個叫 my_house_datapack.zip 的檔案。

2

打開你的世界資料夾

Mac： 在 Finder 裡按 ⌘⇧G，貼上 ~/Library/Application Support/minecraft/saves，按 Enter。
Windows： 按 WinR，輸入 %appdata%\.minecraft\saves，按 Enter。
Linux： 打開 ~/.minecraft/saves。

打開以你世界命名的資料夾，再打開裡面的 datapacks 資料夾。

你應該看到：一個名為 datapacks 的資料夾（可能是空的，這很正常）。

3

把 .zip 放進去

把檔案移到 datapacks 裡。保持壓縮狀態。

你應該看到：.zip 已經在 datapacks 裡面。

4

啟用套件

在遊戲裡打開這個世界。按 T 打開聊天，依序輸入下面兩行。第一行用你自己的檔案名稱：

/datapack enable "file/my_house_datapack.zip" /reload

你應該看到：第一行之後出現「Enabled data pack …」，第二行之後有短暫的停頓。

提示套件「不相容」？ 照樣啟用，它能載入。Craft Block 2.6.0 及之後版本匯出的套件不會出現這個提示。
指令沒有作用？ 這個世界關閉了作弊。暫停 → 對區域網路開放 → 允許作弊：開 → 建立區域網路世界。創造模式世界已經開啟了作弊。
5

選好位置

走到一塊平坦開闊的地面。按 F3（Mac：fnF3），轉身直到 Facing 那一行顯示 east。建築會填滿你前方和右側的地面。

6

輸入指令

按 T，輸入 App 裡的指令（在手機上，旁邊的複製按鈕會把它放進剪貼簿）。Java 裡它帶有一個冒號。對於名為 My House 的建築：

/function craft:my_house

你應該看到：你的建築，和 App 裡一模一樣。

「Unknown function」 跳過了第 4 步，或者名稱不對：Java 用冒號，空格變成底線——My House → craft:my_house。

它到底出現在哪裡？

從你腳下開始，向東、向南延伸。

面朝東（太陽升起的方向），建築就會填滿你前方和右側的地面。App 會告訴你它多寬、多深、多高。建築會原樣放置：放在山丘上，一部分會埋進山裡；放在湖上，水會灌進去。先找平地，再輸入指令。

我想要預覽和精確控制（結構方塊）

遊戲內建的結構方塊會在放置前畫出建築的輪廓，還能讓你微調位置和旋轉。用 /give @s structure_block 取得一個，放下並打開它，把模式設為 載入，在名稱欄輸入你建築的名稱（兩個版本都是 craft:my_house），打開邊界框，調整偏移直到輪廓合適，然後點 載入。一個結構方塊在 Java 中每邊最多 48 格，在 Bedrock 中最多 64 格；更大的建築會分成幾個部分，App 會列出每個部分的偏移。

如果哪裡不對勁

門、火把或花不見了

它們下面需要有實心地面。如果建築落在凹地、坑洞或水上，遊戲在載入的那一刻就會讓它們掉落。把它放在平地上，或者先把地面填平。

水到處流

你的建築裡有池塘或泳池，而它被放在了地面之上，所以水沒有地方停留。把它放低一些、貼著地面，水就會留在池子裡。

轉角樓梯變成了直的

遊戲根據相鄰方塊決定樓梯的轉角形狀，和你手動放置時完全一樣。旁邊沒有樓梯的轉角樓梯是直的；在完整的屋頂裡它就是轉角。

我的動物不在

Craft Block 裡的動物是裝飾，不是方塊。遊戲裡沒有對應的方塊，所以它們留在規劃器裡。匯出前 App 會告訴你有多少隻。

我在 Xbox、PlayStation 或 Switch 上玩

主機無法打開檔案，所以套件不能直接匯入到主機上。在手機、平板或 PC 上匯入（上面的第 1 步），把建築放進一個世界，然後把那個世界上傳到 Realm，再從主機加入該 Realm。沒有 Realm 的話，建築只留在你匯入它的那台裝置上。

一定要是創造模式世界嗎？

不用。任何遊戲模式都可以，包括生存——指令唯一需要的是這個世界開啟了作弊，而作弊只會讓你失去這個世界裡的成就。創造模式只是看建築更方便：可以飛，也沒有東西咬你。

匯出免費嗎？

總共可以免費匯出三個建築；現成世界裡的每個建築都會用掉一次免費匯出。之後匯出屬於 Craft Block Premium。這個頁面上的所有操作都由遊戲本身完成，不收任何費用。
