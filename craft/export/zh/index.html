你的建筑，放进你自己的世界

只需几步，每步只做一件事。用现成世界，打开时建筑就已经立在那里；或者输入一条命令，把建筑放进你已有的世界。无需模组。

导出是做什么的

Craft Block 会把屏幕上的建筑变成游戏能读懂的文件。你在 Minecraft 里打开这个文件，输入一条命令，同样的建筑就会按真实尺寸、一块一块地出现在你的世界里。

?

按钮在哪里

主屏幕 → 长按一个建筑 → 导出到 Minecraft。任何建筑都行：你自己的，或者示例里的。

?

我玩的是哪个版本？

如果你是从 App Store、Google Play、Microsoft Store 安装的 Minecraft，或者在 Xbox、PlayStation、Switch 上玩，就是 Bedrock。如果你在 PC 或 Mac 上通过 Minecraft Launcher 启动，就是 Java。不确定？在游戏标题画面上，Bedrock 会在角落显示类似 v1.21.x 的版本号；Java 显示 Minecraft 1.21.x 和启动器。

?

你会得到什么

Bedrock： 现成世界或包，二选一。现成世界是一个以 .mcworld 结尾的文件，打开就是一个新世界；包是一个以 .mcpack 结尾的文件，打开后一个以你建筑命名的包会进入游戏。Java： 一个以 _datapack.zip 结尾的 .zip，放进你的世界文件夹。它们都很小，只包含你的建筑，别无其他。

导出前应用会显示尺寸：多少方块，多宽、多深、多高。大型建筑会在同一个文件里切成几部分；命令仍然一次把它们全部放好。

?

哪些会带过去，哪些不会

会带过去： 每一个方块，包括楼梯、台阶、门、火把、玻璃、水、植物，以及你设定的朝向。

会被替换： 有几种方块只存在于 Craft Block。应用会列出每一种以及游戏里用什么代替（比如莲花会变成粉色郁金香）。不会有东西悄悄丢失。

留在应用里： 动物和其他生物（它们是装饰，游戏里没有对应的方块），以及你导入的任何材质包——游戏使用自己的材质。

?

它落在哪里

你输入命令时所站的位置。建筑从你脚下开始，向东、向南延伸，所以先面朝东。更多细节和预览确切位置的方法在下面的 它到底出现在哪里？。

?

可以导出几次？

总共可以免费导出三个建筑。每个进入游戏的建筑都会用掉一次免费导出，所以放了三个建筑的现成世界会用完全部三次。之后导出属于 Craft Block Premium。文件本身永不过期：一旦有了它，你可以把建筑放进任意多个世界。

Bedrock 最简单的方法：现成世界

Craft Block 会创建一个全新的平坦创造模式世界，你的建筑已经立在里面。不用输入命令，也不用打开任何设置，你自己的世界完全不受影响。想把建筑放进已有的世界？请看下面的放进自己的世界。

1

选择“现成世界”

在主屏幕长按你的建筑 → 导出到 Minecraft → Bedrock 下的第一个选项 现成世界。

2

选择建筑

应用会问 把哪些建筑放进世界？ 正在导出的建筑已经勾选。再从 你的建筑 和 内置示例 里添加，总共最多 10 个，然后点 创建世界。

它们会在平坦的平原上一排排并肩而立。开通 Craft Block Premium 后，高级示例才会出现在列表中。 没有 Premium 时，每个建筑会用掉一次免费导出，所以列表里能添加的数量就是你剩下的次数。

3

把世界导入游戏

点 保存 .mcworld。接下来因设备而异：

Android 手机或平板： Minecraft 会自动打开并导入世界。为此游戏会重启一次——这是正常的。

iPhone 或 iPad： 会弹出分享面板。选择 Minecraft。如果列表里没有，选择 存储到“文件”，然后打开“文件”应用并点击该文件。

4

打开世界

在 Minecraft 里点 游玩。你现在在 世界 标签页。

点新世界。它和你的建筑同名，如果另外加了两个，名字末尾会带 +2。在区域加载的几秒钟里，快捷栏上方会显示 正在建造你的世界…。

你应该看到：你的建筑就在眼前（建筑很多时，你会站在一个小小的高台上）。这是创造模式：可以绕着飞，也可以走进去。

这个世界的成就是关闭的。 那里开启了作弊，而 Minecraft 在开了作弊的世界里不给成就。这就是代价，也正因如此，你自己的生存世界从来不会被动到。下面的 放进自己的世界 则需要在你自己的世界里开启作弊，那里的成就会永久关闭。

Bedrock：手机、平板、主机、Windows

放进自己的世界： 把建筑放进你已有的世界。步骤多一些：在那个世界开启作弊，然后输入一条命令。

每一步就是一个画面。每步下面的那行字说明成功后你应该看到什么。图片来自 Android 平板和 iPhone；Windows 上看起来一样。

1

从 Craft Block 导出

在主屏幕长按你的建筑 → 导出到 Minecraft → 放进自己的世界（在 Bedrock 下） → 保存 .mcpack。

然后把文件送进游戏——这是唯一一个因设备而异的步骤：

Android 手机或平板： Minecraft 会自动打开并导入包。

iPhone 或 iPad： 会弹出分享面板。选择 Minecraft。如果列表里没有，选择 存储到“文件”，然后打开“文件”应用并点击该文件。

Windows 10/11（Microsoft Store 版 Bedrock）： 把文件发到电脑上（邮件、OneDrive、数据线），双击它。Minecraft 会启动并导入。

Xbox、PlayStation、Switch： 主机无法打开文件。先在手机或 PC 上导入包，在那里把建筑放进一个世界，再通过 Realm 把那个世界带到主机上（在 Realms 上游玩 → 上传世界；然后主机加入）。或者干脆在手机上玩那个世界。

你应该看到：Minecraft 顶部显示 导入成功。

没有任何反应，或者文件在别的地方打开了？ 把文件发给自己（Telegram、Drive、邮件），在设备上打开，长按 → 用其他应用打开 → Minecraft。
2

进入你的世界列表

在 Minecraft 里点 游玩。你现在在 世界 标签页。

新世界：新建 → 创建新世界。已有世界：点名字旁边的 铅笔——不是名字本身。

你应该看到：世界设置，左侧有一列分区（常规、游戏、资源包、行为包……）。

3

开启作弊

左侧列表 → 作弊 → 打开 作弊（旧版本里它在 游戏 下，叫 启用作弊）。游戏会警告这个世界的成就将被关闭——没关系，确认即可。顺便 常规 → 游戏模式 → 创造，建造会更轻松。

你应该看到：作弊开关是绿色的。（只有“成就已禁用”还不够——创造模式世界在作弊关闭时也会这样显示。）

4

为这个世界启用包

左侧列表 → 行为包 → 打开 我的包 → 点带有你建筑名字的包 → 启用。

如果游戏问 更新世界？，选择 仍然添加包——它只是提醒世界里会出现不是它自己生成的东西。

你应该看到：包已经移到上方的 已启用 里。

没有“启用”按钮？ 你正在一个运行中的世界里——那个界面只是显示包。退出世界（暂停 → 保存并退出），然后像第 2 步那样通过铅笔回来。
5

进入世界，选好位置

点 创建（新世界）或 游玩（已有世界）。走到一块平坦开阔的地面。转身，让日出时太阳在你正前方——那就是东方。建筑会填满你前方和右侧的地面。

你应该看到：前方有一块平地，至少和应用显示的尺寸一样大。

6

输入命令

点屏幕顶部的 对话气泡 打开聊天。保存文件时应用已经把命令放进了剪贴板：长按聊天框 → 粘贴。或者手动输入——是用空格隔开的两个词：function 这个词，然后是你建筑的名字。对于名为 My House 的建筑：

/function craft_my_house

点发送。建筑立刻出现。

你应该看到：你的建筑，和应用里一模一样。

“Incorrect permission level for command: function” 作弊已开启，但你的玩家还不是管理员。暂停 → 社交（右上角）→ 点自己的名字 → 管理员。再输入一次命令。
“Unknown command: craft_my_house” 少了 function 这个词——触屏键盘上很容易漏掉。是两个词：/function craft_my_house。
“Cheats aren't enabled in this world” 第 3 步没做：暂停 → 设置 → 左侧列表里的 作弊 → 打开。只开创造模式并不会开启作弊。
你输入的内容变成了聊天消息 开头的斜杠丢了。命令以 / 开头——iPhone 键盘上它在 123 里。
“Unknown function” 这个世界没做第 4 步，或者你在另一个世界里。建筑名里的空格会变成下划线：My House → craft_my_house。

Java：PC 和 Mac

Java 从一个放进你世界文件夹的小 .zip 文件里读取建筑。不用安装任何东西。

1

从 Craft Block 导出

在主屏幕长按你的建筑 → 导出到 Minecraft → Java → 保存 .zip。用任何方式把文件发到电脑上：AirDrop、邮件、Telegram、数据线。不要解压。

你应该看到：电脑上有一个叫 my_house_datapack.zip 的文件。

2

打开你的世界文件夹

Mac： 在访达里按 ⌘⇧G，粘贴 ~/Library/Application Support/minecraft/saves，回车。
Windows： 按 WinR，输入 %appdata%\.minecraft\saves，回车。
Linux： 打开 ~/.minecraft/saves。

打开以你世界命名的文件夹，再打开里面的 datapacks 文件夹。

你应该看到：一个名为 datapacks 的文件夹（可能是空的，这很正常）。

3

把 .zip 放进去

把文件移到 datapacks 里。保持压缩状态。

你应该看到：.zip 已经在 datapacks 里面。

4

启用包

在游戏里打开这个世界。按 T 打开聊天，依次输入下面两行。第一行用你自己的文件名：

/datapack enable "file/my_house_datapack.zip" /reload

你应该看到：第一行之后出现“Enabled data pack …”，第二行之后有短暂的停顿。

提示包“不兼容”？ 照样启用，它能加载。Craft Block 2.6.0 及之后版本导出的包不会出现这个提示。
命令不起作用？ 这个世界关闭了作弊。暂停 → 对局域网开放 → 允许作弊：开 → 创建局域网世界。创造模式世界已经开启了作弊。
5

选好位置

走到一块平坦开阔的地面。按 F3（Mac：fnF3），转身直到 Facing 那一行显示 east。建筑会填满你前方和右侧的地面。

6

输入命令

按 T，输入应用里的命令（在手机上，旁边的复制按钮会把它放进剪贴板）。Java 里它带有一个冒号。对于名为 My House 的建筑：

/function craft:my_house

你应该看到：你的建筑，和应用里一模一样。

“Unknown function” 跳过了第 4 步，或者名字不对：Java 用冒号，空格变成下划线——My House → craft:my_house。

它到底出现在哪里？

从你脚下开始，向东、向南延伸。

面朝东（太阳升起的方向），建筑就会填满你前方和右侧的地面。应用会告诉你它多宽、多深、多高。建筑会原样放置：放在山丘上，一部分会埋进山里；放在湖上，水会灌进去。先找平地，再输命令。

我想要预览和精确控制（结构方块）

游戏自带的结构方块会在放置前画出建筑的轮廓，还能让你微调位置和旋转。用 /give @s structure_block 获得一个，放下并打开它，把模式设为 加载，在名称栏输入你建筑的名字（两个版本都是 craft:my_house），打开边界框，调整偏移直到轮廓合适，然后点 加载。一个结构方块在 Java 中每边最多 48 格，在 Bedrock 中最多 64 格；更大的建筑会分成几部分，应用会列出每部分的偏移。

如果哪里不对劲

门、火把或花不见了

它们下面需要有实心地面。如果建筑落在凹地、坑洞或水上，游戏在加载的那一刻就会让它们掉落。把它放在平地上，或者先把地面填平。

水到处流

你的建筑里有池塘或泳池，而它被放在了地面之上，所以水没有地方停留。把它放低一些、贴着地面，水就会留在池子里。

转角楼梯变成了直的

游戏根据相邻方块决定楼梯的转角形状，和你手动放置时完全一样。旁边没有楼梯的转角楼梯是直的；在完整的屋顶里它就是转角。

我的动物不在

Craft Block 里的动物是装饰，不是方块。游戏里没有对应的方块，所以它们留在规划器里。导出前应用会告诉你有多少只。

我在 Xbox、PlayStation 或 Switch 上玩

主机无法打开文件，所以包不能直接导入到主机上。在手机、平板或 PC 上导入（上面的第 1 步），把建筑放进一个世界，然后把那个世界上传到 Realm，再从主机加入该 Realm。没有 Realm 的话，建筑只留在你导入它的那台设备上。

必须是创造模式世界吗？

不用。任何游戏模式都可以，包括生存——命令唯一需要的是这个世界开启了作弊，而作弊只会让你失去这个世界里的成就。创造模式只是看建筑更方便：可以飞，也没有东西咬你。

导出免费吗？

总共可以免费导出三个建筑；现成世界里的每个建筑都会用掉一次免费导出。之后导出属于 Craft Block Premium。这个页面上的所有操作都由游戏本身完成，不收任何费用。
